🚀 How to Run

1. Install JDK on your system.
2. Open the terminal in the Queue folder.
3. Compile the Java file:

javac ReverseQueue.java

4. Run the program:

java ReverseQueue

Note: Replace "ReverseQueue" with the class name of the Java file you want to execute.
