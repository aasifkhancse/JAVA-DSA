This folder contains Java programs related to Binary Trees. It covers fundamental concepts, tree traversal techniques, operations, and problem-solving approaches using Binary Trees in Java.

- Types of Binary Trees

  - Skewed Binary Tree
- Binary Tree Representation
- Creating a Binary Tree
- Insertion in Binary Tree
- Deletion in Binary Tree
- Tree Traversal Techniques
  - Preorder Traversal
  - Inorder Traversal
  - Postorder Traversal
  - Level Order Traversal
- Height of a Binary Tree
- Count Total Nodes
- Sum of All Nodes
- Count Leaf Nodes
- Search an Element
- Diameter of a Binary Tree
- Check if Two Trees are Identical
- Check if a Binary Tree is Symmetric
- Lowest Common Ancestor (LCA)
- Subtree of Another Tree
- Top View and Bottom View
- Left View and Right View
- Boundary Traversal
- Zigzag Level Order Traversal
- Maximum Path Sum
- Build Tree from Traversals

- Programming Language: Java
- Concept: Data Structures and Algorithms (DSA)
- Data Structure: Binary Tree
