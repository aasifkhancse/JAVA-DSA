Binary Tree in Java

Overview

This project contains the implementation of a Binary Tree using Java.

A Binary Tree is a non-linear data structure in which each node can have at most two children:

- Left child
- Right child

Features

- Create a Binary Tree
- Insert nodes
- Preorder Traversal
- Inorder Traversal
- Postorder Traversal
- Level Order Traversal
- Search an element
- Count total nodes
- Calculate tree height

Technologies Used

- Java
- Data Structures and Algorithms

Binary Tree Structure

        1
       / \
      2   3
     / \
    4   5

Learning Objectives

- Understand Binary Tree concepts.
- Practice recursion.
- Learn tree traversal algorithms.
- Improve problem-solving skills.
