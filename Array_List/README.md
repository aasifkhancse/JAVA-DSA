Java DSA – ArrayList

📌 Overview

This folder contains Java programs and practice problems related to the "ArrayList" data structure.

An ArrayList is a resizable array in Java that allows us to store and manage elements dynamically.

📚 Topics Covered

- Introduction to ArrayList
- Creating an ArrayList
- Adding elements
- Accessing elements
- Updating elements
- Removing elements
- Iterating through an ArrayList
- Searching elements
- Sorting an ArrayList
- ArrayList practice problems

🛠️ Technologies Used

- Data Structures and Algorithms
- Object-Oriented Programming
