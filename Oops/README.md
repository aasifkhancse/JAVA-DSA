🚀 How to Run

1. Install JDK on your system.
2. Open the terminal in the Oops folder.
3. Compile the Java file:

javac Encapsulation.java

4. Run the program:

java Encapsulation

Note: Replace "Encapsulation" with the class name of the Java file you want to execute.
