📚 Arrays – DSA with Java

This folder contains Data Structures and Algorithms (DSA) problems based on Arrays, implemented using Java.

📌 What is an Array?

An Array is a linear data structure that stores multiple elements of the same data type in contiguous memory locations.

Each element can be accessed using its index.
